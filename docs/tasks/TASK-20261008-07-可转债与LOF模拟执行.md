# TASK-20261008-07 可转债与LOF独立模拟执行

## 任务信息与背景

Owner: Codex；status: completed。分支 main，不提交推送。建立可转债与LOF的独立模拟撮合与账本守恒体系。

## 需求与代码范围

1. 在 `market/profiles.py` 中增加 `convertible_bond_profile`（10张每手申报单位、T+0、20%涨跌幅、万分之一佣金免印花税）与 `lof_profile`（100份每手，区分T+0与T+1）。
2. 在 `portfolio/ledger.py` 中集成 `get_multi_asset_profile`，使买入的T+0可转债和T+0 LOF当日即刻可用（`lot.available += qty`），而境内T+1 LOF保留当日不可卖限制。
3. 在 `execution/multi_asset_paper.py` 中实现 `MultiAssetLedger` 与 `MultiAssetPaperBroker`，支持独立模拟账户管理、滑点量化、每手大小检查、强赎/停牌拦截与资金守恒核算。
