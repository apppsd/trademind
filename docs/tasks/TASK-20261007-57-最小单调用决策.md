# TASK-20261007-57 实现JEV与deepseek-flash最小双模型决策链

## 任务信息

- 负责人 / Agent：Codex
- 状态：completed

- 确切修改范围：src/trademind/agents/prompts.py、agents/pipeline.py、tests/test_dual_model_pipeline.py

## 背景与需求

用户确认JEV + DeepSeek架构，DeepSeek固定deepseek-flash。
决策链完整闭环：
最新可见Context → DeepSeek-flash候选分析（包含Trend/Risk/Critic结构化分析） → [WAIT/HOLD短路不进JEV] → 外部TypeSafe JEV窄问题评价 → [若JEV拒绝/失败/超时降级为WAIT] → DeepSeek-flash结构化最终意图 → 代码硬风控 → 模拟OMS。

## 验收标准

- [x] 脚本化四动作/故障覆盖，正常真实候选经JEV再flash汇总，未评审的新风险不能进入OMS；日志可追各段。
- [x] Trend/Risk/Critic三维度结构化分析保留。
- [x] WAIT/HOLD在候选阶段短路，JEV未被调用；空仓HOLD规范化为WAIT。
- [x] JEV失败或不可用时降级为WAIT，阻止新风险。
- [x] JEV审核通过后，flash最终意图生成标准TradeIntent。

## 实施记录与验证

1. 在 `src/trademind/agents/prompts.py` 中注册 `t0_candidate:flash` 与 `t0_final:flash` 提示词模板。
2. 在 `src/trademind/agents/pipeline.py` 中实现 `DualModelPipeline`：
   - 第一阶段：deepseek-flash 候选分析（Trend/Risk/Critic）；
   - 短路检查：WAIT/HOLD 直接生成意图，不调用 JEV；
   - 第二阶段：TypeSafe JEV 窄问题审核（entry_suitable, adverse_move, evidence_sufficient）；若 JEV 失败/报错/拒绝，强制降级为 WAIT，记录原因；
   - 第三阶段：deepseek-flash 结合 JEV 裁决生成最终意图；
3. 编写 `tests/test_dual_model_pipeline.py` 覆盖 5 项核心决策路径测试：
   - `test_dual_model_pipeline_wait_short_circuits`
   - `test_dual_model_pipeline_hold_zero_position_normalized_to_wait`
   - `test_dual_model_pipeline_buy_jev_downgrade_on_failure`
   - `test_dual_model_pipeline_buy_full_success`
   - `test_dual_model_pipeline_sell_full_success`
4. 测试结果：5/5 passed。
