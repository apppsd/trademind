# 容器自动盘中监控

## 任务信息
Codex，main / F:/Project/TradeMind；所有权：execution/auto_paper.py、compose.yaml自动服务、run_auto.py操作入口、run_container.py并发防护、api/app.py只读自动状态与static状态行、自动运行/启动器测试；文档见同步契约。不覆盖账户/预算与其他待修复Task。

## 背景与需求
用户要求自动开市启动和持续监控，不需要每次手动启动。容器启动后使用上海交易日历自动判断连续时段，盘中按既有有界paper执行，午休/休市等待，恢复交易时自动重试。

## 非目标
不实盘、不降低资金/质量/预算/权限门槛，不改变现有模型，不清历史；不通过Codex定时对话代替生产调度。

## 验收标准
一个容器supervisor确保serve与paper子进程互斥；停止时排空paper；时段结束限制单次运行期限，循环保留真实门禁与模型费用限制。失败退避，未知worker状态停止重试；持久化中文状态及原paper报告。启动器禁止与auto服务并发writer。午休实际部署验证等待，模拟测试覆盖开市/午休/重试/停止；不为了验证自动化额外收费。
