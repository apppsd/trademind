## 背景与问题

根因与实际档案见[Issue25-01](../issues/ISSUE-20261025-01-买入计划退出条件未关联SELL动作.md)。计划可允许BUY、包含有效exit_conditions却遗漏SELL；持仓后即使退出条件命中也不向JEV提供SELL。现有提示约束不足，校验仅验证“SELL必须有退出条件”。独立Mock链已复现，无真实持仓损失证据。

## 需求与解决方法

1. 先复现Issue的BUY→成交100份→退出命中却不提供SELL，保存修复前证据。
2. 本批采用明确规则：**允许BUY的可开仓计划必须同时允许SELL，并有非空可计算退出条件**。允许WAIT-only与无新仓的SELL/HOLD/WAIT；SELL仍须持仓、可卖数量与条件支持。只依赖硬止损的BUY计划暂不作为隐含例外。
3. 在计划校验边界统一执行规则，Planner同样拒绝不符合契约的草稿。不能静默向模型动作集合补SELL、不能用正则改响应、不能把非法草稿变为BUY；走现有拒绝/WAIT及诊断路径，不新增无限收费修复重试。
4. 更新策略提示和合成示例，要求完整入场/退出权限；升级策略Prompt或契约版本，使旧非法计划不再缓存命中。缓存读取应用同一校验规则，旧计划失效时记录分类原因、按现有节流刷新或WAIT，不修改历史档案、不重写原始模型输出。
5. 核对“失效条件命中拒绝计划”和“策略退出”之间的职责；不得借本修复让JEV越过计划/Guard，程序止损、time_stop、尾盘退出仍独立工作。
6. 重要策略契约变化同步ARCH-006 implementing中的本次设计与需求；不把旧实现基线重写为已验证实盘。
