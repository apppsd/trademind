## 需求与解决方法

1. 展示当前/过期/被替换/失效计划，中文趋势/风险/反证/原因与有效时间；用真实StrategyPlan而非把旧Thesis当快速链计划。
2. 条件表显示字段中文名、比较门槛、当时值/时点、满足/不满足/未知，明确entry AND、exit OR、invalidation OR；不得拿现在行情回填过去条件。
3. 时间线按行情可见→策略→JEV→程序复核→意图→订单→Fill，缺档节点显示未知；JEV置信度称回答置信度，不当赚钱概率。
4. 交易记录按决策/订单/成交/资金变动分tab，默认成交，无成交给正确空态；中文默认列，长ID折叠但可复制核对。
5. 服务端筛选/分页/详情与返回上下文，支持标的/日期/动作/原因；部分成交/余量/撤单/过期/UNKNOWN不同文案。
6. 可跳到行情历史范围或关联计划；技术详情仅脱敏白名单，零模型调用补故事，不按同名字符串关联。
