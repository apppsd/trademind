## 背景、需求与主方案

**首发只选密集Vue SAMPLE卡片与子页，不实施iframe。** 只读参考 `F:/Project/trader/prototype/frontend-20261026/` 的index/account/explorer/instrument/states页面及README，保留trader的确定性策略、运行履历与候选/计划区分。不能只更换TM标题、复制流水线节点冒充trader业务。

理由：壳已有Vue/ECharts/只读组件；半屏宽度要按窗适配，独立导航和深链由Vue统一管理。原型iframe虽然可快速铺满页面，但会引入重复站点导航、内外选中态/历史同步、静态资源挂载路径与半屏断点适配；对本批独立导航验收并不更稳。原型是内容/视觉参考，不复制维护第二套HTML站点。详细内容矩阵和样例边界见[简报](../research/BRIEF-20261030-dual-ops-cockpit-claude.md)。
