# TASK-20261007-46 建立独立T0模拟账户与成交闭环

- 负责人 / Agent：Codex

## 背景与需求

独立500虚拟资金paper账户与数据库，支持T+0 ETF分钟级模拟撮合闭环：
1. 模拟OMS消费提交后才可见的有效分钟报价或日线报价，避免同根bar回填与未来数据穿透；
2. T+0当日已成交多头可卖（available_quantity即时释放），T+1股票当日锁定；
3. 支持BUY→持仓→当日SELL→清仓完整生命周期，费用、剩余现金、权益与仓位实时更新；
4. 严格校验模式（拒绝shadow/live下单）、跨账户授权、订单防重与回滚恢复。

## 验收标准

- [x] 脚本化BUY→持仓→当日SELL→清仓实际改变500虚拟账户，费用/剩余cash/仓位可复算。
- [x] shadow/Live绝不提交；旧股票T1当天卖出拒绝；跨账户授权拒绝。
- [x] 同bar不得提前成交，缺报价不成交；无重复成交或虚增权益。

## 实施记录与验证

1. 在 `src/trademind/execution/paper.py` 中为 `PaperBroker` 扩展分钟行情撮合逻辑（`_eligible_minute_bars` 与 `_fill_at_minute_bar`），确保仅撮合订单提交时间后且可见的分钟bar，支持ETF三位小数精度定价及保守滑点计算。
2. 结合 `Ledger.apply_fill` 对 `settlement_rule == "T+0"` 的即时可用支持，打通T+0日内买入即时可卖链路。
3. 编写 `tests/test_t0_oms_execution.py` 覆盖 4 项核心测试：
   - `test_t0_etf_buy_and_same_day_partial_and_full_sell_loop`: 500元账户买入100股ETF，当日可卖，日内平仓盈利结算，费用准确，权益自洽。
   - `test_t1_stock_same_day_sell_rejected`: 验证普通A股（T+1）当日买入后 available_quantity 为0，Guard 严格否决当日卖出。
   - `test_oms_anti_lookahead_and_missing_quote`: 验证不可在提交前bar提前成交，缺行情时订单保持 ACKNOWLEDGED。
   - `test_oms_rejects_shadow_or_live_mode_and_cross_account`: 严格阻断跨账户与非paper模式。
4. 测试结果：4/4 passed，全套175项测试全部通过。
