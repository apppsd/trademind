## 需求与解决方法

1. 中文关注列表+右侧大图详情，支持中文/代码搜索、仅观察/可交易资金筛选与本地收藏；收藏不修改后端universe。
2. 主图先分时、1m/5m/15m K线，成交量副图；周期按钮按API能力开放，未知日K/盘口/NAV明确不可用。VWAP/均线仅画有证据的数据。
3. 十字线、拖动/缩放、回到最新、范围选择、图例、可选历史事件图层；新bar更新不强拉用户正在看的历史。切标的取消旧请求，实例resize/dispose随页面生命周期。
4. 以source_time/available_at/as_of、coverage/partial解释时效；缺口断线，午休/隔夜分段，不插入0价/平滑虚线冒充真实。前收缺失不称今日涨跌。
5. Fill成交点、意图点、订单提交/撤销、程序退出使用不同类型；点击打开对应记录或历史策略；不能将模型BUY权限/意图伪装成交。
6. 可选最多3标的归一化比较和图片导出，标注基准/范围/币种和模拟标签；首期核心未完时可明确延期，不据此改交易策略。
