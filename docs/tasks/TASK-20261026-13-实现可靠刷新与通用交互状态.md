## 需求与解决方法

1. 冻结GET信封校验与错误类型，TypeScript不能替代运行时数组/对象/null检查；非JSON/空响应/HTTP失败分类为中文错误，不把服务原HTML注入DOM。
2. 单资源单在途、超时AbortController、切页/日期/标的取消、请求世代号防迟到覆盖；首屏每资源一次，不由名称加载重复刷新全页。
3. 独立资源并发但上限可控；错误退避、页面不可见降频/暂停、用户返回先重验数据年龄，成功后恢复正常频率。GET与POST完全分开，POST绝不自动重试。
4. 保留最后成功快照同时显示as_of/stale/partial，首次骨架/刷新/空/错/未知不同状态；一个慢接口不锁整页。
5. 本地偏好仅收藏/显示排序/周期/减少动效，不存token/凭据/原始API响应；变更偏好不产生交易操作。
6. 键盘焦点/标签/弹层关闭、图表可读摘要、系统减少动效、长文本与缩放统一实现，作为所有页面共同基线。
