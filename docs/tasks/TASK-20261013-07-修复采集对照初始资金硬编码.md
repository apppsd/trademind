## 实施记录（2026-10-15）
1. **fast_archives.collect**：`cfg.t0.initial_cash != 500` 门禁改为"正且有限"（`not cash.is_finite() or cash <= 0` 拒绝，零/负/NaN/Infinity在任何行情/模型访问前拒绝）；`pipe.ensure_account(initial_cash=cash)` 改用配置值（原字面500）；bundle 顶层新增 `initial_cash` 与 `initial_cash_source: config.t0.initial_cash`（资金来源+配置指纹，runtime_configs 照旧记录完整公开配置）。
2. **fast_comparison.compare_archives**：删除 `!=Decimal('500')` 字面门禁。新增循环前预检（在任何回放账户创建前拒绝，避免半开管道泄漏）——逐old/new标签从runtime_configs+t0_configs求有效资金：非正/非有限拒绝；runtime记录的paper.initial_cash与t0不一致拒绝；A/B两标签资金不同拒绝（"A/B资金不同明确拒绝"保留）。循环内基准 `base=cfg.t0.initial_cash`（Pipeline构造时 `_validate_mode_isolation` 同步paper←t0，实际入金即该值）；`peak/trading_net/net_after_model_cost/initial_cash` 全部改用 base；rules 基线账户跟随A/B资金保持可比。无runtime的旧档案走AppConfig默认500，行为与原500口径一致（历史档案无资金字段时已有的 `runtime_config_unrecorded` gap 显式标记不完整，不伪造默认）。
3. **prompt_paper.PromptPaperAccount**：新增 `initial_cash=None` 参数（None→cfg.t0.initial_cash 默认500兼容）；非正/非有限在建账前拒绝；`peak`、报告 `initial_cash/net_pnl` 改用配置值，报告新增 `initial_cash_source`（explicit_parameter / config.t0.initial_cash，不猜测）。prompt_experiment 调用点不传参，默认行为不变。

语义口径（按Issue候选1+3）：**初始金额以配置 t0.initial_cash 为准，默认500**；采集/比较报告带资金值与来源，A/B可比性门禁（等额、正数、paper一致）保留。
