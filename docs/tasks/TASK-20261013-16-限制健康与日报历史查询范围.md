## 实施记录

### 已完成
- `read_intraday_health`（paper_run.py）：model_calls 与 strategy_plan_history 查询加 `created_at`/`available_at` 窗口谓词（上海日 ±2 天 UTC ISO 边界，容忍 'Z'/'+08:00' 等存储格式），精确上海日过滤仍留在 Python 内；逐行语义不变。
- intents 最近意图回退改为窗口内按 rowid 倒序取至多 8 行、Python 精确日/账户挑选（原 `ORDER BY rowid DESC LIMIT 1` 在乱序插入时会错过当日意图；生产按时间追加时两者等价）。
- `read_snapshot`（daily.py）：新增可选 `window=(start, stop)`；calls/intents ±2 天、contexts 7 天回看（保留“最近一次行情时间戳”显示）、plans ±2 天，均走新索引；events 有意保持全量（期初账本按全部事件重放，无可信边界快照，不丢历史）。`generate_report` 传入报告日窗口；`window=None` 保持旧无界读取（已有调用方兼容）。
- intents 缺 `created_at` 列（从未迁移的 v1 文件只读打开）时自动回退无界读取，不报错。
- 测试：test_daily_report.py 新增参数化等价（1/30/365 天历史 vs 仅当日基线全量相等 + 当日内容存活断言）、多账户隔离、EXPLAIN QUERY PLAN 索引与行数上界、空日+缺表负例；test_auto_paper.py 新增健康窗口有界（昨日失败计入 SQL 边际但被精确过滤、当日失败仍计数）。
