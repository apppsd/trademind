# TASK-20261008-09 多市场候选筛选与完整验收

## 任务信息与背景

Owner: Codex；status: completed。分支 main，不提交推送。建立多市场候选过滤、流动性选优、严格模型调用配额与 CLI 接口。

## 需求与范围

1. 实现 `market/selector.py` (`MultiAssetCandidateSelector`)：
   - 权限、规则、标的有效性、资金/保证金多层确定性过滤。
   - 流动性（Turnover）排序，各市场受 `top_k_per_market` 与 `max_total_candidates` 严格截断。
   - 零模型调用（`model_calls: 0`），报告每类标的扫描数、合格数、选中数及否决原因分布。
2. 在 `runner.py` 中增加 CLI 入口 `trademind market-select [--top-k K] [--max-total N]`，支持一键筛选。
3. 保证模型每日调用配额共享，不随全市场几百只标的增加而放大模型预算。

## 不包含

不追求高频逐笔，未授权资产不自动放行。
