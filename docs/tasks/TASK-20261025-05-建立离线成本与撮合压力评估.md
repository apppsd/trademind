## 问题与需求

当前PaperBroker用后续可见bar触价、默认滑点撮合剩余全部数量，没有真实盘口队列/参与率约束。小额短线还受最低佣金与模型成本影响。需要报告在更差费用、延迟和未成交假设下，净结果如何变化；不能仅凭理想模拟和stub回放判断赚钱。

## 解决方法

1. 建立离线输入契约：绑定版本/时点的档案意图、后续可见分钟bar、资金配置、模拟费率、模型usage费用及unknown。只读档案，独立内存/临时账户，禁止读取凭据/补发模型/重生成历史决策。
2. 输出两类结果：A为一手/给定名义金额的往返盈亏平衡成本表（无需真实成交）；B为足够档案上的执行假设压力回放。数据不够时B=insufficient_data，A仍可完成；空交易、缺配置、unknown费用不能写成盈利或稳定。
3. 冻结并记录评估场景，至少默认5bps/边及10、20bps/边；最低佣金按当前模拟0.1/边与假设1、5/边；填充延迟按下一合格bar及再延后1、2根；参与率/触价未成交采用明确保守假设。上述是敏感性参数，不称真实券商报价，不用于生产。
4. 延迟/成交压力必须重算成交、持仓、可用现金与后续订单合法性，不能仅在旧净值上减一笔常数。保留订单限价，不强制限价外成交；缺bar/未知量/一字板不能按理想量全成。部分成交、剩余单和尾盘无法清仓明确报告；若能力暂不支持则将该场景标unsupported，不能伪称已覆盖。
5. 交易费用从交易损益中只扣一次；模型成本独立汇总，现金账户与实验净结果区分；零交易仍计实际模型成本，未知费用使净结果unknown，预留不是账单。盈亏平衡表给出本金/敞口基数和模型成本分摊假设，不能把5元上限当每天必花。
6. 生成中文Markdown/JSON，包含输入指纹、样本范围、场景定义、净收益/费用/回撤/成交与未成交量/未平仓、限制。压力工具不调生产门槛以获得更好收益，也不选择结果最好场景冒充基线。

## 实施记录 / 未验证内容

2026-10-25 实施（Claude Code，uv Python 3.12.15）：

- **A 成本表**：`breakeven_table()` 按生产 compute_fees 语义逐腿计算（max(名义×费率, 最低佣金)+卖出印花税+过户费，quantize 0.01）+ 双边不利滑点；100/200元 × 5/10/20bps × min 0.1/1/5 共18行，全部手算可复核；注明模型成本摊销公式与“5元上限不是每天必花”。
- **B 压力回放**：8个冻结场景（baseline 5bps/0.1 + 10/20bps + min 1/5 + delay 1/2根 + participation 10%）；保守撮合（买=bar_high×(1+bps)封限价、卖=bar_low×(1−bps)托限价、限价外不成交、缺bar不补未来信息、参与率按bar成交量封顶且剩余数量明确报告）；隔离内存账户重算成交/持仓/可用现金/后续订单合法性；状态 ok / insufficient_data / incomplete / unsupported；费用每笔成交只扣一次，模型成本独立汇总，unknown→组合净额unknown；输入sha256指纹，结果确定性（同输入逐字节一致）。
- **证据包**：合成BUY→SELL包（价格取2026-10-23 local-1k档位，明确标注synthetic）8场景全ok，baseline交易净额−0.50、每+5bps/边恶化0.20、min5恶化至−10.30；真实local-1k 2026-10-23零意图包8场景全insufficient_data，组合净额=−真实模型成本0.196991805180。汇总报告：docs/research/20261025-cost-stress-verification.md。

**未验证**：真实成交、真实模型收益、券商费率与盘口真实性均未验证；本工具是敏感性评估，不校准JEV市场胜率，不接入实盘，不构成策略正期望证据。
