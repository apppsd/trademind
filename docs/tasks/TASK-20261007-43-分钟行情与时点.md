## 实施记录

1. 领域模型：在 `src/trademind/market/base.py` 中引入 `MinuteBar`，规范北京时区、纳秒级可见时间、单位与数据来源元数据。
2. 数据清洗与聚合：在 `src/trademind/market/quality.py` 中实现 `normalize_minute_bars`（去重、版本覆盖、坏价检测）与 `aggregate_minute_bars`（严格隔绝上午 11:30 与下午 13:00，午休不跨段凑 bar）。
3. 适配器与路由：在 `FixtureAdapter` 与 `AKShareAdapter` 中增加 `get_minute_bars`；在 `DatasetRouter` 中统一审计与路由调度。
4. 特征与时点重建：在 `src/trademind/context/features.py` 中实现 `compute_minute_features`（VWAP、ATR 14、短周期收益率、量比以及纯描述性市场状态 `market_regime`，绝不包含下单动作）与 `minute_bars_visible_at` 严格防未来函数过滤。
5. 上下文快照构建：在 `src/trademind/context/builder.py` 中提供 `build_minute`，包含新鲜度检查（超时自动标记 `missing_fields["freshness"]`），挂载分钟证据。
