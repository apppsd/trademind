# TASK-20261021-01 管理员页面配置运行时密钥与服务地址

## 背景与需求（用户 2026-10-21 提出）

用户要求：原本必须自行在 `.env` 中配置的内容（如大模型 API Key），可以在工作台前端做一个管理员页面直接配置，免于手工编辑文件。

## 范围

- 新增受控制令牌保护的运行时设置存储与 API（GET 列表 / PUT 保存 / DELETE 清除）。
- 密钥落盘于 gitignored 的 `data/runtime/admin_settings.json`（容器内随 `data/runtime` 可写挂载）。
- `load_config` 在加载凭据时应用覆盖；显式进程环境变量仍优先于管理页覆盖值。
- 工作台前端新增「管理员设置」区块：查看掩码值、保存、清除。
- 修复 `.env.example` 中"JEV official API adapter is not implemented yet"过期注释（本轮校验发现，与本页直接相关）。

## 非目标

- 不提供 `TRADEMIND_API_TOKEN`（管理令牌本身）的页面修改——避免自锁，仍由 `.env` 引导配置。
- 不提供模型型号（`llm.model`）的页面修改——遵守"不得静默换 DeepSeek 型号"硬约束。
- 不做热重载：保存后需重启 serve/auto 进程生效，页面明确提示。
- 不改变 replay/shadow 隔离：凭据覆盖仅在 load_credentials=True 时应用。

## 可验证验收标准

1. 未配置控制令牌时管理接口 403；令牌错误 401；与既有控制端点行为一致。
2. PUT 保存后：响应与 GET 列表均只含掩码值，完整密钥不出现在任何响应体中。
3. 非白名单键、空值、含换行/控制符的值被拒绝（400）。
4. `load_config(load_credentials=True)` 应用覆盖值；隔离模式（False）下不应用，凭据仍为空。
5. 显式进程环境变量优先于管理页覆盖值。
6. DELETE 清除后覆盖不再生效。
7. 新增测试通过，全量 pytest 通过；`check_docs.py` 0 错误。

## 计划

1. `config.py`：白名单 specs、读写 `admin_settings.json`（原子写）、掩码、应用覆盖、描述列表。
2. `api/app.py`：3 个管理端点（全部 `require_token`）。
3. `static/index.html`：管理员设置区块（沿用右上角控制令牌输入）。
4. `tests/test_admin_settings.py`：认证/掩码/白名单/持久化/优先级/清除。
