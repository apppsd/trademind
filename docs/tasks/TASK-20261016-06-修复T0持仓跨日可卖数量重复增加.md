## 实施记录（2026-10-17，Claude Code 认领实施）

**根因与修复**（src/trademind/portfolio/ledger.py）：T+0买入时`available`与`bought_today`同时增加，日切rollover无差别`available+=bought_today`→T0部分二次解锁（100+100>100→ValidationError）。修复：T0买入只立即解锁（`available+=qty`），**不计入`bought_today`**（其语义=待T+1解锁量，对T0恒为0）；`apply_fill`与`rebuild_from_events`两处对称修改。`_load`的`bought_today=quantity-available`重算在新语义下天然一致（T0→0），三条恢复路径（同进程/快照重启/事件重放）统一。

**验证**：tests/test_ledger.py新增5项——T0买入即解锁且bought_today=0、T0未平仓跨日（同进程日切不再抛错）、三恢复路径状态一致（含日切后）、部分卖出跨日边界、T+1股票日切语义不变；ledger/recovery/t0_oms_execution套件25 passed；全量578+项通过（见下方汇总）。未知日历不解锁、同日重复日切无操作由既有测试保留。
