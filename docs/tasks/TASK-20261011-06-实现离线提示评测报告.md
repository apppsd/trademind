## 验收标准
- 默认saved-output模式严格零HTTP、零provider初始化、零订单/账户写入；读固定样本及保存响应，输出原子JSON和可阅读Markdown报告。
- 固定字段：报告/数据集/Schema/提示/模型版本、输入指纹、样本来源、总例数/总尝试/成功/错误/缺响应、各指标分子分母、失败case_id；缺响应写incomplete，不判通过。
- 分别输出JSON/契约失败、禁止动作建议、Guard实际放行、BUY正例与风险退出覆盖、无机会误交易；未知指标为null且说明原因。
- P50/P95须说明样本量、耗时单位与统计范围；费用区分estimated/settled/pending，缺usage不记零；硬失败不能被综合平均分抵消。
- A/B使用同样输入和标签，提示版本不同但不混淆旧/新profile架构对照；旧报告兼容，命令返回明确pass/fail/incomplete状态。
