## 修法

1. **B01-①+② 决策层（fast_decider.py / fast_pipeline.py）**：`FastDecider` 接受 `quote_max_age_seconds=180`，有效期限两处固定 180 改为 `min(180, 配置值)`（配置阈值真实生效；保留 180 硬上限）；入口与 JEV 后既有 now 比对不动（按当前时钟判定）。fast_pipeline 构造 decider 时透传该参数。`intent_max_age_seconds:180` 诊断保持独立（review R4 既有约定，intent 期限经 `decision.valid_until` 的 min() 自动继承更严约束）。
2. **B01-①+③ 执行层（pipeline.py）**：`reference_price` 抽出返回 (price, bar_time) 的内部实现；执行点先按旧 as_of 取**原始决策快照**（语义与现状逐位一致），再按 `self._now(as_of)`（当前时钟；replay 模式 = as_of，行为零变化）复核报价，复核价作为 Guard/OMS 参考价；两次结果与复核结论记入审计 `reference_price_recheck`（复检拒绝 → 先记审计再抛 NotFresh，走既有 data_reject 分类）。风险退出（`_risk_exit`，:461/655）保持 as_of 定价不动——保护性退出不得因行情老化被阻断。
3. **B02（builder.py）**：`build_minute` 内抽统一估值报价入口（质量合格 + 可见 + 新鲜三门一次执行），主标的与其他持仓都走它。主标的失败语义逐位保留：质量违规 → 同文 `DataUnavailable`、空窗 → `missing['bars']`、过期 → `missing['freshness']`；其他持仓任一门不过 → `valuation_incomplete`（拒绝窗口不得入 `prices`，ledger 回退均价成本，Guard 拒新风险）。

### MAJOR · 审计"决策快照"不是模型实际用的那份 —— 属实，已修

复现点三条均实读证实：①原 `pipeline.py:606` 在模型返回后按旧 as_of **重新调 router 查询**决策快照——重选源后可能拿到模型从未见过的报价；②异步消费路径 `_fast_model_result` 返回模型轮旧 source（snap 重绑为 source），而审计 decision.as_of 用的是消费轮 as_of；③拒绝场景 recheck price/bar_time 置 null（异常发生在赋值前），被拒报价无法事后还原。

修法（`src/trademind/pipeline.py`）：

1. **决策快照冻结**：新增 `_frozen_decision_quote(snap)`——直接从**模型实际消费的 snap**（异步路径 = 消费轮重绑后的模型轮 source；t0 读 `aux['minute_bars'][-1]`，日线读 `aux['last_bars'][-1]`）取 (price, bar_time)，**不再发生执行点 router 重查**，决策调用也不可能再抛异常。审计 decision.as_of 改用 `snap.as_of`（异步路径 = 模型轮 as_of）。
2. **复核三态化**：`_reference_quote` 拆为薄包装 + `_reference_quote_state(instrument_id, at) -> (price, bar_time, reject_reason)`；拒绝时 price/bar_time **携带被拒窗口的报价**（质量/过期分支取最后可见行；仅无任何行时为 None），复核审计行 recheck 字段不再置 null；行为语义不变（`_reference_quote` 照旧抛 NotFresh 同文原因，估值环与 reference_price 包装不受影响）。
3. 同步拒绝路径结果不变：复核拒绝 → 先写审计再抛 NotFresh → 既有 data_reject 分类（白名单原因逐字不变）。

新增测试（断言审计决策快照=模型实际输入）：`test_async_consume_audits_model_round_snapshot`（异步路径：decision.as_of/bar_time=模型轮 NOW/NOW-20s，recheck=消费轮 NOW+30/NOW+10s，旧实现下 decision 会被记成消费轮）、`test_reselection_cannot_replace_decision_snapshot`（模型等待后 router 改服务偏移窗口：decision 仍冻结在模型轮 bar，仅 recheck 携带新窗口——旧实现的执行点重查会记成偏移窗）。
