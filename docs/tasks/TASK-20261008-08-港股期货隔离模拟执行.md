# TASK-20261008-08 港股与期货隔离模拟执行

## 任务信息与背景

Owner: Codex；status: completed。分支 main，不提交推送。建立港币现金隔离与期货保证金交易模拟执行。

## 需求与范围

1. 在 `market/profiles.py` 中增加 `hk_stock_profile`（HKD币种、每手股数、印花税0.1%、佣金0.03%最低15港币）与 `futures_profile`（合约乘数、保证金率、多空双向、5元最低佣金）。
2. 在 `domain/instruments.py` 与 `domain/enums.py` 中扩展市场枚举（XHKG, XSGE, XDCE, XZCE, CCFX, XINE）并允许期货配置 `short_selling_allowed=True`。
3. 在 `execution/multi_asset_paper.py` 中实现双币种隔离账本 `MultiAssetLedger` 与期货保证金结算模式：
   - 港币与人民币资金完全隔离，零串币（买港股只扣HKD，买现货ETF只扣CNY）。
   - 期货开仓只占用保证金（`price * qty * multiplier * margin_rate`），平仓释放保证金并结算 `(exit - entry) * qty * multiplier - fees` 差额盈亏。
   - 连续指数代码不可交易，仅真实月份合约可成交。

## 不包含

不实盘、不假设拥有全部期货权限、不自动换汇或追加真实资金。
