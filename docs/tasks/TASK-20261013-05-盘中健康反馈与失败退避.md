## 背景与需求
Issue13-02确认自动状态只在子进程结束后判断策略失败。新增中文状态：等待开市/行情不足/有效策略观望/策略请求失败退避/预算限制/持仓风险处理/需要人工核对，Docker健康仍单独表示进程存活。

盘中摘要必须只读或由现有paper writer发布，限当前账户/当前轮及日期，展示最近策略成功时间、明确失败原因、连续失败数、预算估值及下一允许请求时间。不以审计行数冒充请求次数，不对旧记录猜测缺失分类。选择可测试的有界退避策略并写清重置条件；仅模型失败触发，合法WAIT/冷却/资金不足不混为API失败。恢复依赖有效响应或规定的预算内检查，不新增绕过免费门禁的探针。
