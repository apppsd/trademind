### 已完成
1. **显式版本注册与指纹追踪** (`src/trademind/agents/fast_prompts.py`)：
   - 登记 `STRATEGY_PROMPTS` 注册表（包含 `strategy-2` 基线与 `strategy-3` 增强版）；

2. **晋级门禁评估逻辑** (`src/trademind/evaluation/prompt_eval.py`)：
   - 实现 `evaluate_promotion_eligibility`：强制硬约束零失败、检查 BUY 覆盖率（默认 >= 80%）与 Exit 覆盖率（默认 >= 80%），杜绝“全 WAIT 逃避风控”的作弊行为；
   - 真实档案门禁拦截：若真实 holdout bundle 为空或缺失，返回 `decision: INCOMPLETE`，阻止在缺乏真实留出证据时盲目晋级。
3. **安全回滚验证** (`src/trademind/evaluation/prompt_eval.py` / `src/trademind/agents/strategy_planner.py`)：
   - 实现 `verify_version_rollback`：证实版本切换后旧计划缓存因版本隔离自动失效（cache miss），但冷却时间戳（cooldown attempts）、账户资产、持仓和订单历史完全保留，不造成状态污染。
4. **单元测试验证** (`tests/test_prompt_promotion.py`)：覆盖注册表、哈希差异、错误禁止动作拒绝、全 WAIT 拒晋级、空真实档案阻止晋级及回滚持久化核验（6 项测试全部通过）。
