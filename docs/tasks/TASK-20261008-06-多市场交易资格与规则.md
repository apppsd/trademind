# TASK-20261008-06 核实账户与逐只交易规则

## 任务信息与背景

Owner: Codex；status: completed。分支 main，不提交推送。严格遵循用户权限确认与逐只真实规则门禁。

## 需求与范围

新增 `market/rules.py` 与 `market/access.py`。
1. 建立 `MarketRule` 与官方核验的 `CANONICAL_RULES` 库，覆盖境内ETF、LOF、可转债、港股（直连/港股通）与境内期货（普通商品/特殊品种/金融期货），包含生效期、官方URL、T0/T1、每手股数/张数、价格档位、费率、合约乘数、保证金率、停牌与强赎状态。
2. 建立 `check_permission` 与 `evaluate_eligibility`，严格区分港股直连与港股通（港股通仅可买入名单标的，其他标的报 `hk_connect_ineligible`），期货特殊合约权限（`futures_special` / `futures_financial`）独立检查，强赎可转债（`convertible_bond_called_early`）与停牌（`instrument_suspended`）独立拦截。

## 不包含

无券商连接/实盘/收费采购，不读取账号与Key，不把普通证券账户视为拥有所有市场权限。

## 验收标准与计划

- [x] 用户确认信息写入本地忽略配置；未确认项仍unknown，规则生效日期可复现。

- [x] 至少每类1只真实样本核验（ETF、LOF、可转债、港股直连/通、普通/特殊/金融期货）。
- [x] 对境内ETF、LOF、可转债、港股直连/港股通、普通/特殊期货分别测通过与否决。
