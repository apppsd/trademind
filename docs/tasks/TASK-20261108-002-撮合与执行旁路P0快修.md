### MAJOR-1 · 量化后夹回限价破坏 tick 格点 — 已修

- 修法语义（Codex 推荐的"拒绝"分支，写明）：限价语义 = 不劣于该价成交；tick 格点半取整越过限价约束时**拒绝成交**（返回 None），不再夹回限价。量化 + 限价同时成立（最终价为 tick 整数倍且满足限价方向）才可能成交。限价本身在格点上时格点取整永不越界（raw ≤ 限价 ⇒ round(raw) ≤ round(限价) = 限价），行为与 R1 一致；拒绝只发生在非格点限价（模拟/测试构造产物）。
- `paper.py` `_quantize_fill_price`：返回类型 `Decimal | None`；BUY `round(raw) > limit` → None，SELL `round(raw) < limit` → None；两个撮合调用点对 None 返回不成交。
- `multi_asset_paper.py` `execute_order`：同一语义，越界 `return None`，删除 min/max 夹回。
- 测试：`test_lattice_round_crossing_off_lattice_limit_rejects_fill`（复现反例 tick=0.01 限价 2.005/2.004 → 均拒绝）；`test_multi_asset_off_lattice_limit_refused_when_round_crosses`（复现反例 tick=0.20 限价=现价=400.30 → 拒绝且零入账、不改终态）；`test_lattice_round_within_limit_fills_on_tick`（限价+tick 双约束成立：非格点限价 400.30、raw 400.12 → 格点 400.20 ≤ 限价 → 成交，断言 `% tick == 0` 且 ≤ 限价）。
