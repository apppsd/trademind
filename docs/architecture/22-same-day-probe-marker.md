# ARCH-022 同日探针标记与探针额度耗尽退避

## 背景
[Issue16-01](../issues/ISSUE-20261016-01-自动会话反复探针耗尽额度阻断下午运行.md)：一小时有界会话反复带 `--probe-models`，5次过门禁的启动（2失败+3成功）耗尽 probe 10/10，午后8轮被挡——每次重启进程都重付探针对（2次/对），而非模型故障却表现为持续阻断。

## 语义（冻结，2026-10-17实施）
1. **同日探针标记**（`_probe_fast_models`）：成对探针成功后持久化 `fast-probe-ok:{account}`（北京日+config_hash+verified）。同日、同配置哈希、同账户的重启**跳过付费探针**，capability 由标记置真。失效条件：北京日变更、任一配置变化（哈希不含当日即失配）、或当日任一次实探失败（探针失败即清除标记——供应商现在就是坏的，重启必须重探）。
2. **信任边界与证据**：标记只跨**进程内重启语义**（同一监督树、同日、同配置），不跨日、不跨配置、不替代日切后重探。若供应商在标记后中断，首个真实策略调用会响亮失败（预约+审计+分类，13-04诊断可用）——与任何盘中供应商故障同一失败面，不新增未审计风险。
3. **额度耗尽退避**：免费门禁通过但探针对预算不可用（`probe_budget_exhausted`）时，报告携带独立标志，supervisor 退避为**每小时**检查（原5分钟×8次无意义阻断），状态注明"非模型故障、次日额度重置自动恢复"。首次设计将“本轮未运行”当作无持仓风险；Task17-10已以既存到期持仓反例证伪，启动保护路径待Task16-02收口。
4. **报告区分**：`probes` 字段区分 `live`/`same_day_marker`；blocked 报告区分探针额度耗尽与其他门禁——额度/总请求/费用/认证错误的可见性满足验收。

## 不做
不提高额度/费率/词元；不跳过JEV/Flash验证（同日首次仍实探）；不跨日复用认证；不改风险阈值。

## 验证
runner/auto_paper 离线回归（标记跳过HTTP、失败清除、跨日失效、配置变化失效、预算耗尽退避3600s），见Task16-02验证节。
