# ISSUE-20261007-14 现有shadow不提供模拟持仓与盈亏

> 当前开放面（2026-10-08）：原始问题（shadow 不产生模拟盈亏）已由 TASK-46 的独立 paper 账户在组件级解决；本 Issue 保持 open 的真实原因是**真实双模型 500 账户 BUY→SELL→清仓完整闭环未验收**，受 ISSUE-20261007-12/13 与 ISSUE-20261008-04 阻塞。关闭条件不变，见下方验证结果。

## 问题表现

guard/guard.py 对 RunMode.SHADOW 直接 VETO shadow_no_execution；OMS模拟入口仅paper/replay。用户新影子测试希望观察虚拟持仓/成交/盈亏，当前只记录判断。

## 影响

直接启用shadow跑几天只能得到判断记录，不能得到用户期望的成交账户结果。

## 环境与复现方式

2026-10-07 当前本地未提交实现，Windows / Python 3.12。

项目原先将shadow定义为只观察，和用户口头“影子盘”的新含义不同。属于需求与实现差距，不取消旧安全边界。
