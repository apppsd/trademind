# 档案采集与对照工具硬编码500与1000初始金额配置冲突

## 问题表现

修复实施已由[TASK-20261013-07](../tasks/TASK-20261013-07-修复采集对照初始资金硬编码.md)立项，pending；支持配置资金但保留A/B可比性和账户隔离门禁。当前Issue保持open。

2026-10-12 初始金额调整为 1000（`config/t0-container.local.toml`、`config/t0-fast.local.toml` 的 `[t0]`/`[paper]` 均已为 "1000"，账户余额经当日入金 500 后为 1000）后，以下工具因硬编码 500 检查拒绝运行：

1. `src/trademind/evaluation/fast_archives.py:123`：`cfg.t0.initial_cash != 500` 即 `raise ValueError('isolated 500 CNY T0 paper configuration required')`。**已实测**：`.venv/Scripts/python.exe scripts/collect_fast_archives.py --samples 1 --max-seconds 300` 返回 `{"status": "failed", "error": "ValueError"}`，exit 1（拒绝发生在任何行情/模型访问之前）。
2. `src/trademind/evaluation/fast_comparison.py:149`：对照回放要求 `cfg.t0.initial_cash` 与 `cfg.paper.initial_cash` 均为 500，否则报错。
3. `src/trademind/evaluation/prompt_paper.py:105`：报告输出硬编码 `'initial_cash': '500'` 及 `net_pnl = equity - 500`。

## 影响

- TASK-20261009-17（真实共同双链档案采集）的默认入口当前不可用，直接阻塞 17 → 08（对照校准）→ 09（完整闭环验收）主线。
- 500 是当初"隔离 500 元小资金"安全约束的编码化，调整初始金额后该约束需要显式重新决策，不能静默失效。

## 环境

2026-10-12，Windows 宿主 `.venv`，配置 `config/t0-fast.local.toml` / `t0-container.local.toml`（initial_cash = "1000"）。

## 复现方式

```cmd
.venv\Scripts\python.exe scripts\collect_fast_archives.py --samples 1 --max-seconds 300
```

返回 `{"status": "failed", "error": "ValueError"}`，exit 1。

## 原因分析

Task17/08 实施时将"隔离 500 元"作为字面常量写死，未与配置联动；2026-10-12 账户入金并将配置调整为 1000 后，两处事实冲突。

## 尝试过的方法

仅代码审查与上述只读实测，未改代码。

## 最终解决方法
2026-10-15由[TASK-20261013-07](../tasks/TASK-20261013-07-修复采集对照初始资金硬编码.md)按候选1+3实施：初始金额以配置 `t0.initial_cash` 为准（默认500兼容），三工具的500字面门禁全部改为"正且有限的配置资金"；prompt_paper 盈亏基准同步读配置。可比性门禁保留并前移：非正/非有限拒绝、runtime记录的paper与t0资金不一致拒绝、A/B两档案资金不同拒绝；采集/比较/提示报告带资金值与来源字段，历史无资金档案沿用 `runtime_config_unrecorded` 显式缺口，不伪造默认。

## 验证结果
工程口径resolved（2026-10-15）：新增6项回归（collect接受1000/拒绝0、-5、NaN、Infinity；比较端到端1000回放、A/B不一致拒绝、paper≠t0拒绝；PromptPaperAccount配置资金报告），相关七套件100 passed，全量577 passed/0 failed。实施与命令见该Task验证节。真实共同档案采集（Task17）与对照校准（09-08）仍按原门禁以真实验收，不因工具可运行关闭。

## 剩余风险

在修复前，任何依赖 `collect_fast_archives.py` 或对照回放的验收都会以 ValueError 失败，可能被误判为行情/模型问题。
