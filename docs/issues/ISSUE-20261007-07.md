# ISSUE-20261007-07 未来行情与Thesis泄漏且回放未离线隔离

## 问题表现与影响

audit-repro future/future_thesis/replay_isolation：更晚行情提前成交、更晚研究被更早查询返回、replay保留DeepSeekProvider和AKShare。

首版验收阻塞，不能因为现有93项测试通过视为功能完成。

## 环境与复现

Windows、项目 .venv Python、SQLite、fixture/stub。动态场景运行 .venv/Scripts/python.exe docs/research/20261007-audit-repro.py；静态证据见 [验收报告](../research/20261007-code-audit.md)。

## 原因分析

try_fill不使用now限制可见bar；Thesis仅检查valid_until，没有研究时点上界；Replay直接继承真实provider/data配置且修改调用者配置。

## 代码范围

src/trademind/execution/paper.py、pipeline.py、evaluation/replay.py、配置。

## 尝试过的方法

独立验收核对与临时库复现，没有修改应用代码。

## 最终解决方法

成交仅使用下个交易日及之后、available_at<=poll now 的行情，未触价可推进后续 bar，滑点不能越限价。Thesis 检查来源上下文与真实可用时间；账户含未来事件则拒绝历史决策。Replay 深拷贝、清除凭据、固定 fixture/stub、新建内存库，按日切→到时成交→决策→估值顺序执行，禁止复用运行库。

实施记录：[TASK-20261007-33](../tasks/TASK-20261007-33-修复验收.md)。

## 验证结果与剩余风险

本缺陷已通过强断言回归；全套 133 passed，原失败证据与最终命令见 [复验报告](../research/20261007-code-audit.md#修复复验2026-10-07)。真实供应商能力与前瞻观察仍未验证，不与本缺陷关闭混为一谈。
