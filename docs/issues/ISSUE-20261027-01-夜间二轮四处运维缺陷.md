# ISSUE-20261027-01 夜间二轮四处运维缺陷

Codex 独立审查（2026-10-27）发现，四处均已在代码中确认，隔离复现成立。根因与关闭条件如下；实施记录归 [TASK-20261027-01](../tasks/TASK-20261027-01-修复夜间二轮审查缺陷.md)。

## 根因

1. **备份失败后不再重试**（`scripts/run_local.py`）：`_sqlite_backup` 先 `sqlite3.connect(target)` 建空文件，备份中途失败留下 0 字节残留；`_backup_if_due` 只查 `target.exists()` → 之后每天跳过。复现：0 字节备份 + 第二次启动跳过。
2. **代理地址可能泄露凭据**（同文件不可达分支）：打印完整 `HTTPS_PROXY`；若含 `user:pass@` 会进终端/日志。
3. **告警在心跳持久化之前同步发送**（`src/trademind/execution/auto_paper.py` tick）：webhook 超时会推迟心跳写入且失败每 tick 重试；`persist_final_state`（终态路径）不经过通知逻辑 → 终态 halt 漏报。
4. **看门狗重复通知同一事件**（`scripts/watchdog_heartbeat.py`）：每次陈旧运行都发通知，无事件级去重。

## 影响与边界

均不阻断交易主链（通知默认未配置、看门狗未注册计划任务、备份仅数据安全冗余），但都属于无人值守保障的名义能力与实际行为不符。10-26 体检通过不等同于本批缺陷不存在；代理 TCP 可达也不等价于 JEV 请求成功（真实探针仍以开盘预检为准）。

## 关闭条件

- [x] 备份改为临时文件+原子替换，失败不残留目标；既有 0 字节残留可被清理并重试（回归钉住）。
- [x] 代理不可达/不可解析的输出全部经脱敏（userinfo 以 `***` 替代），回归断言输出不含凭据。
- [x] 告警移到心跳持久化之后；每事件最多重试 3 次后放弃；`persist_final_state` 终态路径同样触发告警（回归钉住）。
- [x] 看门狗同一事件只通知一次，心跳恢复后清除告警标记、下次事件重新告警（回归钉住）。
- [x] 全量 pytest 0 失败、check_docs 0 错误；150 重启部署并于开盘前复检晨间体检。
