# 结果标签成熟时间与终点行情选择不一致

## 表现与影响范围
OutcomeService固定期限标签存在三项同一生命周期边界问题：登记时将07:00直接套用输入tzinfo，等价时刻在UTC与+08下到期相差8小时；mature未校验当前时间或行情可见时间，提前调用仍写final；查询终点至下一交易日的闭区间后直接取最后一根，实际使用次日收盘价，收益标签偏离horizon定义。

Pipeline旧默认链提交订单后调用register，故登记入口可达；src中未发现mature/maturity_candidates业务调用，快速链和真实标签受影响未证实。没有模型请求、真实亏损、生产提前成熟或策略表现结论。中优先级，在启用成熟反馈前修复；不是现有T0交易自动链新增阻塞。

1. 同一瞬间2026-10-12T10:00+08与02:00Z分别register：两条horizon分别10-19T07:00+08和10-19T07:00Z。10-19T08:00+08调用maturity_candidates，前者已入选、后者未入选。前者甚至早于开盘；真实日线可用时间还应遵守适配器发布延迟，而不是仅到日期。

## 根因与区别
memory/memory.py::register把输入日期/tzinfo当市场时区；maturity_candidates只比较该错误horizon；mature不检查到期/可见性且bars[-1]误用next日。Fixture与Router的闭区间返回符合自身接口，不应为标签修复改变其行为。Issue18-01是仓储记忆查询，18-02是Reflector消费和新经验生成时间，均未覆盖本生产者标签计算；不重开旧Issue07-07行情/Thesis/Replay隔离。
