# 可交易性诊断低估持仓与挂单敞口

独立复现：快照有513100持仓10000份但没有该标的价格，另有513050新鲜价0.949，诊断仍输出513050资金可达，只在总报告提醒缺价持仓按0计值。陈旧/未来持仓价格也进入price_map；open_orders仅计数、不占单票/总敞口；重复持仓行被最后一行覆盖。与“全部冻结限额内”结论不一致。

影响仅限新离线诊断，生产Guard未修改、未证明有真实下单风险。实施与验证见Task26-01。

## 2026-10-26 修复与复验

tool_version=2：持仓仅用新鲜可见价格估值，缺价/陈旧/未来价格使新仓诊断保持数据不足；重复持仓累加。BUY在途剩余量×限价计单票及总敞口承诺，现金冻结仍用reserved_cash只扣一次；不完整/UNKNOWN挂单保持数据不足，SELL不提前释放敞口。输出现金/单票/总敞口余量、规则及输入指纹。移除1000手隐含截断，改合法上界内二分含费手数。

新增缺价/陈旧/未来持仓、重复行、BUY承诺及冻结不重复扣、挂单缺字段反例通过，历史三ETF样本结论不变且已重新生成。生产数量/Guard/配置未动。工程resolved，真实成交能力不因此关闭。
