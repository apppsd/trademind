# ISSUE-20261030-03 双系统大屏导航与内容失衡

## 已观察事实与证据

2026-10-30 用户反馈“交易系统大屏几乎全是TradeMind，trader看不见”。本轮定向读取当前工作树源码与静态原型；以下为源码事实与可推导的导航行为，未进行浏览器复现或视觉实测。路径相对 `F:/Project/TradeMind`，行号对应本轮未提交工作树。

## 根因与风险边界

当前实现是在TradeMind单系统路由上追加一个双窗运行流页面，没有把导航、页面生命周期和内容所有权改为双系统。左窗缺业务深度，右侧已有七个完整页面，形成结构性失衡。视觉精致度尚未实测，不把主观反馈改写成已测量的布局结论。

本Issue只管双系统信息架构、内容完整度与视觉对等；[Issue30-02](ISSUE-20261030-02-跨项目流水线观测缺少统一只读语义.md)继续管真实双源只读语义及接线，不合并、不代关闭。新首发以显式SAMPLE演示为默认，不继承既有自动GET/轮询；保留既有适配成果，后续接线仍归06。样例金额有固定时点/单位，未知为“—”，不伪造真实资产、运行状态或交易因果。

禁止交易写入、资金/风控修改、模型调用、研究作业、凭据访问、SSH/150、部署/重启、commit/push；不改trader代码。ARCH-027保持implementing。本轮为Codex规划文档，未认领Claude实现。
