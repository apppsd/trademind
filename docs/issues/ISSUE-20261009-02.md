# 快速链时效与恢复边界缺陷

复现：分钟数据已老化150秒，JEV结果仅余30秒，TradeIntent却得到180秒；模拟BUY提交成交后注入holding marker写入异常，持仓存在且订单已完成，但没有期限。

根因：FastDecisionPipeline遗漏DecisionOutcome.valid_until；成交与期限分别提交。另有模型同步阻塞运行循环、回放统一旧profile、flash仅预留费用和运行诊断不足。

修复与验证见 [TASK-20261009-10](../tasks/TASK-20261009-10-修复快速决策架构问题.md)。真实模型/行情门禁不属于本 Issue。

解决：最短有效期继承；Ledger.atomic覆盖成交/期限，故障回滚及重启重建；CLI单模型线程与主线程再校验；分开费用口径，完善profile/时间/配置回放与诊断。280测试通过，其中新增14项故障与行为回归。另修复回放首轮日切造成账户版本错误的根因。真实认证/费用/行情仍保持原Issue开放。
