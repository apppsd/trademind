# 反思入口缺少成熟与生成可见时点门禁

## 问题与影响边界
Reflector声称只消费成熟结果，实际reflect未检查is_final/censored_reason或available_at，直接调用模型并保存Reflection和CONFIRMED记忆。经验available_at直接沿用Outcome.available_at，晚生成的经验因此能在生成之前的历史查询中出现。全部反例使用UTC，与Issue18-01的字符串跨时区比较无关；修复仓储时区不能修复错误的生产者时间。

当前src中只有Reflector定义、导出与Pipeline导入，没有reflect业务调用；OutcomeService.mature/maturity_candidates也未发现业务调用。现有工程模块契约不成立，但没有证据表明当前自动快速链已执行反思、已发费用或已污染生产决策。此Issue中优先级，是启用该反馈入口前必须处理的独立改进；不等同真实交易阻塞。

## 环境与复现
Windows/.venv Python3.12，临时SQLite，Outcome合成样本，LLM为SimpleNamespace(kind=STUB, model=synthetic-only, complete=Mock)，返回固定parsed lesson；patch memory.memory.utcnow为2026-10-18T10:00:00Z，禁止socket和真实凭据文件读取。

逐场景新建库、构造Repository/MemoryStore，再调用Reflector.reflect(decision_id=outcome.decision_id, outcome=outcome, context_digest='synthetic', trace_id='synthetic')：

| 场景 | 输入 | 实际行为 |
|---|---|---|
| 未成熟 | is_final=False, censored_reason=not_mature, available_at=now | Mock调用1次，reflections1行，CONFIRMED记忆1行 |
| 尚未可用 | is_final=True, available_at=now+1天 | 同样在available_at之前调用并保存 |
| 晚生成 | is_final=True, available_at=10-17 10:00Z，生成时间10-18 10:00Z | MemoryStore.visible(10-17 22:00Z)返回该经验，payload.created_at却为10-18 10:00Z |
| 正常控制 | final且available_at=now | now前1微秒不可见、now可见 |

所有样本horizon_end=now-2天，避免以未来horizon制造歧义；非final样本return_ratio=None，final样本0.01。每例使用独立临时库，原始返回/数据库行均已断言。四例执行后库已关闭并清理，2份源码哈希运行前后稳定：memory/memory.py=602fc1fc2f5aa517620077642b727a34ba7ac1d8b903b9ee10e10cff9b4708fe；domain/outcome.py=99eb1e1ab3d08ed3bd6dc97d23a606bcbc99bf73acc600d791f613bfce775984。

## 根因与范围
Reflector.reflect仅依赖调用方传入对象，提示词中的“已成熟”不能代替程序门禁；Outcome schema只约束final与censored_reason组合，不证明调用时刻可用。记录新经验时用旧标签的available_at代替新经验真实生成可用时间，仓储看到的是合法却错误回填的时间。受影响函数位于src/trademind/memory/memory.py::Reflector.reflect、MemoryStore.record_event调用点；不要求全局改变record_event历史事件导入语义。

## 解决状态与关闭条件
**2026-10-19已由Task18-05修复（工程口径，resolved）**：`Reflector.reflect`在LLM调用与任何持久化前执行程序门禁——`is_final=False`（含censored样本）或`available_at > now`直接抛ValueError拒绝，零副作用（Mock调用0、两表0行）；不检查horizon_end，提前平仓final语义保留。时钟经`Reflector.__init__(clock=)`注入，LLM返回后取completed_at，新经验`available_at=max(outcome.available_at, completed_at)`——晚生成经验不再回填到标签可用时刻之前的历史。三反例（未成熟/尚未可用/晚生成）与正常控制、提前平仓final控制由`tests/test_reflection_boundaries.py`（5项）钉住；全量623 passed/0 failed。反思自动链仍未接入（src无业务调用方），生产、真实模型费用与策略效果未验。
