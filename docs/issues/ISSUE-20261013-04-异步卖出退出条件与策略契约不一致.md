# ISSUE-20261013-04 异步卖出退出条件与策略契约不一致

## 问题表现
build_fast_state按任一退出条件满足开放SELL，Pipeline._fast_model_result却对BUY和SELL都要求全部条件满足。只有一个退出条件触发的有效SELL会被标为NotFresh，而同步动作构造允许该SELL。

证据级别：隔离复现的确定性代码缺陷。本轮仅分析，尚未实施修复。

## 影响
可能延迟正常策略卖出；程序止损/持有期限退出是另一条路径，不能替代策略退出契约。本轮没有真实持仓或订单证据，不认定其造成今日零成交。

## 环境
2026-10-13，Windows / Python 3.12.10，main / F:\Project\TradeMind，宿主当前未提交源码。其他Agent正在修改相关文件，实施前须再次核对。隔离实验只用Mock/Future/临时SQLite/fixture，不读取.env、不联网、不调用模型、不操作生产账户或容器。

## 复现方式
构造合法StrategyPlan（SELL/WAIT），退出条件close<2和ret_1m<-0.01；当前close=1.5、ret_1m=0，计划/意图未过期，账户版本不变。用已完成Future交给实际Pipeline._fast_model_result：any=True、all=False，返回NotFresh: async strategy conditions changed before execution。用SimpleNamespace/Mock提供账户快照，无Provider或网络。

### 代码定位
- src/trademind/context/fast_state.py:37：SELL使用any(exit_conditions)。
- src/trademind/pipeline.py:323、326：选出exit_conditions后统一not all(...)。
- src/trademind/agents/strategy_planner.py：发送给模型的condition_contract固定entry_match=all、exit_match=any。
- tests/test_fast_architecture_repairs.py现有异步测试覆盖BUY/过期/慢模型，未覆盖两个退出条件只满足一个。

## 原因分析
异步执行复核复用了入场的AND逻辑；正常策略退出的OR语义未贯穿生产链路。

## 尝试过的方法
已做文档与对应源码/现有测试对照、以上隔离核查；没有修改实现或运行状态。实验过程和整体去重见[TASK-20261013-11](../tasks/TASK-20261013-11-代码对照改进规划.md)。

## 最终解决方法
2026-10-14 由 [TASK-20261013-12](../tasks/TASK-20261013-12-统一异步卖出退出条件语义.md) 实施修复：
- `context/fast_state.py`新增`conditions_allow(action, plan, features)`作为条件判定单一来源：BUY=入场条件非空且全部满足；SELL=退出条件非空且任一满足；其他动作False。空条件集合永不授权交易（`all([])`缺陷路径消失）。
- `pipeline.py::_fast_model_result`异步复核改用该函数（旧`not all(...)`统一AND语义删除）；同步动作构造（fast_state状态构建）共用同一函数——两路径对同一计划/特征判定一致。
- 重检其余环节（计划valid_at/失效条件/最新行情/账户版本/TTL）原样保留，未靠去掉重检修复。

## 验证结果
已验证（2026-10-14，Windows / Python 3.12，隔离tmp SQLite，无网络）：
- 语义单元：单条件满足SELL授权、空集两侧拒绝、BUY全条件语义（test_conditions_allow_contract_semantics）。
- 真实Pipeline异步链：两退出条件满足其一时SELL经Guard/OMS成交（test_async_one_of_two_exit_conditions_executes_sell）；执行前市场翻转后全部不满足→拒绝且无订单（test_async_no_exit_condition_matching_blocks_sell）；空退出集合不向JEV提供SELL（test_empty_exit_conditions_never_offer_sell）。
- 相关文件回归76 passed；全量回归481 passed（--ignore=tests/test_multi_asset.py，环境缺pandas）。
未验证：真实盘中异步SELL（真实行情/模型延迟组合）、容器内生效、真实交易影响（归TASK-20261013-06真实盘中验收）。

## 剩余风险
修复后风险收敛为：模型产生无退出条件的SELL计划时按空集合拒绝——设计行为；真实盘中表现未验。不得为通过验证放宽行情/资金/预算门禁，真实闭环仍由原验收任务判断。
