# ISSUE-20261007-06 OMS缺少风控授权校验

## 问题表现与影响

audit-repro auth：Guard VETO 后 OMS 返回 ACKNOWLEDGED。

首版验收阻塞，不能因为现有93项测试通过视为功能完成。

## 环境与复现

Windows、项目 .venv Python、SQLite、fixture/stub。动态场景运行 .venv/Scripts/python.exe docs/research/20261007-audit-repro.py；静态证据见 [验收报告](../research/20261007-code-audit.md)。

## 原因分析

submit未检查ALLOW、授权是否真实存在/匹配/过期、账户版本/模式/数量和价格，guard_id也未使用保存记录的真实键。

## 代码范围

src/trademind/execution/oms.py、GuardResult绑定、提交边界。

## 尝试过的方法

独立验收核对与临时库复现，没有修改应用代码。

## 最终解决方法

保存并引用同一 Guard ID，授权绑定意图哈希、数量、限价、账户、模式、版本及期限；OMS 在事务中重检持久记录、kill switch 与未对账订单，一次授权只创建一个订单。shadow 仅观察、禁止订单和冻结；replay 只在隔离离线环境模拟。

实施记录：[TASK-20261007-32](../tasks/TASK-20261007-32-修复验收.md)。

## 验证结果与剩余风险

本缺陷已通过强断言回归；全套 133 passed，原失败证据与最终命令见 [复验报告](../research/20261007-code-audit.md#修复复验2026-10-07)。真实供应商能力与前瞻观察仍未验证，不与本缺陷关闭混为一谈。
