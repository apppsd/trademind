# 跨日预算覆盖未知费用并错记迟到结算

## 表现与根因

DailyModelBudget 原先换日重新构造状态，下次预约覆盖同一 coalesce 行，前日失败 pending 丢失；reconcile 用完成日定位，跨午夜请求结算可能混入新日费用。

## 解决与验证

每日当前行覆盖前归档为 `model-budget:{account}:history:{day}`；Decimal预约附所属上海日期，结算回写该日当前/历史状态。snapshot 只读，不迁移、不删除费用。

tests/test_budget_rollover.py 验证：午夜只读不变旧账、次日预约保留旧pending、归档后迟到结算仅改旧日、首笔新日预约前结算正确、第三日旧记录仍在、Decimal兼容。完整证据见[收尾报告](../research/20261010-engineering-completion.md)。

## 剩余限制

未知usage仍须供应商证据才能对账，不自动释放或推断为0。归档使用既有Schema，没有新增后台对账服务。
