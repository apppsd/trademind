# ISSUE-20261013-05 单持仓行情失效阻断其他标的风险退出

## 问题表现
Pipeline._run_decision在建立当前标的Context和执行_risk_exit前，先要求全部持仓reference_price成功。任意其他持仓报价NotFresh/ProviderError都会使本次决策提前返回。

证据级别：隔离复现的确定性控制流缺陷。本轮仅分析，尚未实施修复。

## 影响
多持仓时，行情正常标的的止损、持有期限或尾盘退出也可能不可达；这是故障传播边界缺口，区别于原Issue07-13的真实分钟质量未验。单持仓自身无新鲜价时仍应安全拒绝，不能制造价格成交。

## 环境
2026-10-13，Windows / Python 3.12.10，main / F:\Project\TradeMind，宿主当前未提交源码。其他Agent正在修改相关文件，实施前须再次核对。隔离实验只用Mock/Future/临时SQLite/fixture，不读取.env、不联网、不调用模型、不操作生产账户或容器。

## 复现方式
用Pipeline.__new__构造隔离控制流依赖，账户快照含A=513100.SH、B=513050.SH；A报价函数抛NotFresh，B报价返回1.5。调用实际_run_decision(B,10:00)：error=NotFresh: isolated other-symbol stale quote，build_minute调用0、_risk_exit调用0。此实验只证明提前返回，无实际下单。

### 代码定位
- src/trademind/pipeline.py:347：valuation字典先遍历全部持仓调用reference_price。
- 同文件_run_decision：on_new_trading_day/build_minute之后才在约370行调用_risk_exit。
- 同文件_risk_exit：当前标的时限/止损/尾盘经Guard/OMS退出。
- tests/test_fast_architecture_repairs.py:test_slow_model_does_not_block_risk_exit只覆盖模型慢，未覆盖另一持仓行情失效。

## 原因分析
账户全量估值被放在每只证券的确定性风险退出之前，整体估值失败与逐标的风险处理共用同一异常出口。

## 尝试过的方法
已做文档与对应源码/现有测试对照、以上隔离核查；没有修改实现或运行状态。实验过程和整体去重见[TASK-20261013-11](../tasks/TASK-20261013-11-代码对照改进规划.md)。

## 最终解决方法
2026-10-14 由 [TASK-20261013-13](../tasks/TASK-20261013-13-隔离持仓行情故障与风险退出.md) 实施修复（设计见[ARCH-016](../architecture/16-position-valuation-isolation.md)）：
- 估值改逐持仓独立try：单持仓`NotFresh`/`ProviderError`只记入`valuation_failures`（标的+异常类型），不再中止整轮决策；健康标的的确定性风险退出照常经Guard/OMS。
- Guard新增`valuation_complete_provider`：任何持仓估值不完整时BUY以`incomplete_account_valuation`被VETO（新增风险门禁），SELL/风险退出不受影响。
- `valuation_failures`在context构建前/T0构建后/fast链替换diagnostics后三处保证可见；context builder成本回退路径取并集看最坏情况。
- `on_new_trading_day(prices_complete=...)`：不完整估值不落新日基线。失效标的不交易、不补价、不改持仓。

## 验证结果
已验证（2026-10-14，Windows / Python 3.12，隔离tmp SQLite，无网络，真实Pipeline+Mock行情路由）：
- A stale/B fresh：B止损SELL成交、A零订单零成交持仓原样、无新日基线、全程零模型调用（test_stale_holding_does_not_block_other_symbol_risk_exit）。
- 估值不完整BUY VETO（test_incomplete_valuation_vetoes_new_buy）；全部报价失效整轮拒绝零订单零模型调用（test_all_quotes_stale_refuses_without_orders）。
- 相关文件回归76 passed；全量回归481 passed（--ignore=tests/test_multi_asset.py，环境缺pandas）。
未验证：真实盘中多种行情故障组合、容器内生效、真实交易影响（归TASK-20261013-06真实盘中验收）。

## 剩余风险
修复后风险收敛为：真实行情源的长时间部分失效会使新开仓被持续VETO（保守设计行为）；deadline/尾盘退出在真实触发时点的表现未验。不得为通过验证放宽行情/资金/预算门禁，真实闭环仍由原验收任务判断。
