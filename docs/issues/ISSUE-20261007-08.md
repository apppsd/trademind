# ISSUE-20261007-08 成交与账本非原子且日切不可恢复

## 问题表现与影响

audit-repro atomic_fill/rollover：fill=1但持仓=0且重试不补记；可卖3000重建为0。

首版验收阻塞，不能因为现有93项测试通过视为功能完成。

## 环境与复现

Windows、项目 .venv Python、SQLite、fixture/stub。动态场景运行 .venv/Scripts/python.exe docs/research/20261007-audit-repro.py；静态证据见 [验收报告](../research/20261007-code-audit.md)。

## 原因分析

fill先独立提交后apply_fill；失败重试被fill幂等丢弃。日切只修改内存，没有可重放事件，重建无法恢复可卖量。

## 代码范围

src/trademind/execution/oms.py、storage/db.py、portfolio/ledger.py、恢复。

## 尝试过的方法

独立验收核对与临时库复现，没有修改应用代码。

## 最终解决方法

SQLite 显式事务及嵌套 savepoint；Ledger.atomic 同时回滚内存。成交、账户事件/快照、订单、预留和审计同事务提交。持久日切事件，交易日与同日幂等检查，恢复 bought_today；快照丢失从事件恢复。UNKNOWN 订单阻止新增风险且必须有明确对账结果。

实施记录：[TASK-20261007-34](../tasks/TASK-20261007-34-修复验收.md)。
