# ISSUE-20261007-05 资金冻结虚增净资产且无法释放

## 问题表现与影响

audit-repro reserve/cancel：1000000冻结148148后净资产1148148；撤单前后预留均148148。

首版验收阻塞，不能因为现有93项测试通过视为功能完成。

## 环境与复现

Windows、项目 .venv Python、SQLite、fixture/stub。动态场景运行 .venv/Scripts/python.exe docs/research/20261007-audit-repro.py；静态证据见 [验收报告](../research/20261007-code-audit.md)。

## 原因分析

cash未扣冻结，但equity再加reserved；reserve使用decision_id，release使用intent_id导致预留键不匹配。

## 代码范围

src/trademind/portfolio/ledger.py、guard/guard.py、execution/oms.py。

## 尝试过的方法

独立验收核对与临时库复现，没有修改应用代码。

## 最终解决方法

净资产=cash+market_value，reserved_cash 是 cash 的子集。冻结统一绑定 intent_id；撤单、终态与过期未提交授权释放预留，部分成交缩减剩余预留。敞口包含预留，日损基准扣除净出入金，持仓按可见市价估值。

实施记录：[TASK-20261007-31](../tasks/TASK-20261007-31-修复验收.md)。

本缺陷已通过强断言回归；全套 133 passed，原失败证据与最终命令见 [复验报告](../research/20261007-code-audit.md#修复复验2026-10-07)。真实供应商能力与前瞻观察仍未验证，不与本缺陷关闭混为一谈。
