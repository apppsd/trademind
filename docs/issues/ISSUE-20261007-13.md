# ISSUE-20261007-13 T0 ETF规则与分钟行情未覆盖

## 问题表现

当前 market/profiles.py 以股票板块构建profile；adapters/live.py 已见 get_daily_bars 股票日线接口，context消费日线。未建立有官方依据的T0 ETF白名单和可验证ETF分钟/报价链。

## 影响

仅将universe改成ETF代码可能仍按股票T1/费用/数据解释；不能进行可信日内模拟，也不能声称免费实时盘口可用。

## 环境与复现方式

2026-10-07 当前本地未提交实现，Windows / Python 3.12。
阅读 market/profiles.py、domain/instruments.py、market/adapters/live.py、context/builder.py；对照新分钟与逐证券规则需求。此缺口无需真实API失败才能确认。

## 原因分析

现有版本实施范围是普通股票日线，用户的新范围产生规则及数据缺口，不把旧范围设计称成已发生资金错误。

只读核对代码与公开官方资料，形成规划；未改应用实现、未调用模型或盘中数据。
