# 成本回放时序与输入门禁不完整

独立复现的原行为：

- 初始现金150，A于06:50提交BUY/06:51成交，06:52提交SELL/07:00才成交，B于06:53提交BUY/06:54成交。旧回放按意图序先入账07:00卖出，再接受06:54买入，使用未来现金。
- BUY quantity=-100被接受，产生现金净额+95，属于输入门禁错误。
- pending_cny=5、unknown=false时combined_net仍返回已知-0.2，缺失model_cost还默认0。
- 无available_at/as_of边界、对每个订单独立分配同一bar参与率、忽略保留现金/敞口/整手、单次SELL就算完成往返，未平仓现金流未提供权益估值/回撤。

影响新离线压力工具及其报告可信度，不涉及生产PaperBroker或真实账户。修复应使用提交/可见成交事件顺序、冻结现金/可卖数量与合法规则、共享bar参与容量、显式输入可见时间与档案截止、未知成本保留unknown、部分/未平仓状态与权益/回撤分开报告。缺少必要契约应拒绝或标incomplete/unsupported，不能伪称已验证。实施与验证归Task26-01。

## 2026-10-26 修复与复验

输入及tool版本升2；强制as_of/available_at与空仓账户资金限额，校验正整手、核验T0 ETF、tick、非负费用/成交量及bar价格。按提交/mark/成交事件排序，提交冻结现金或持仓，同刻不预支成交；缺后续bar保持pending，不以缺数据假定取消。每bar共享整手参与率，非法SELL不静默缩量；不利tick取整并保留限价，未知/零量和单价bar不假定可成交。缺成本或pending>0使组合净额unknown，已结算估值另列；未平仓报告权益损益/现金流和采样回撤，不再以存在一笔SELL就称完整往返。

新增未来卖出融资、迟到可见bar、缺成本/pending、负/零/非整手数量、坏价格/费率、共享容量、部分卖出/未清仓、冻结限额及单价bar回归通过。重算合成报告：baseline交易损益-0.70、含模型估值-0.90；5与10bps可因tick相等，20bps交易损益-0.90。真实零交易包仍insufficient_data、扣已知模型估值约-0.197；不能推导策略优劣。仅工程resolved，不声称真实流动性验收。
