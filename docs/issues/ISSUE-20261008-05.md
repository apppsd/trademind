# ISSUE-20261008-05 新市场执行能力缺口

## 已观察行为

五市场行情入口已接入，实际返回327只可转债与724个期货合约；现有MarketProfile/Guard/Paper/ledger早期仅是人民币A股和核验ETF语义，不支持其他品种。

## 原因与边界

港币资金/股票每手数量、港股通逐只资格、期货保证金/合约乘数/多空/结算日历、可转债临停/强赎/数量、LOF交易资格均需独立适配。下载行情不能证明用户已开通权限；用户尚未提供确认信息。原get_profile对任意非ETF SH/SZ代码兜底A股，已明确拒绝可转债等未知执行品种，避免误套T1或股票费用。

## 解决措施（2026-10-11）

通过 TASK-20261008-06 至 TASK-20261008-09 完整实施并落地 [ARCH-011](../architecture/11-multi-asset-execution.md)：
1. **规则与权限门禁（Task-06）**：
   - 建立 `src/trademind/market/rules.py` 与 `CANONICAL_RULES` 官方核验规则库，支持 T+0、每手股数、价格档位、费率、合约乘数、保证金率、停牌与强赎状态。
   - 建立 `src/trademind/market/access.py`，细分账户权限（`cn_fund`、`convertible_bond`、`hk_stock_direct`、`hk_stock_connect`、`futures_standard`、`futures_special`、`futures_financial`），拦截非港股通标的及未授权品种。
2. **可转债与LOF模拟执行（Task-07）**：
   - 在 `market/profiles.py` 与 `execution/multi_asset_paper.py` 中支持可转债 10 张申报单位、T+0 交易、强赎拦截与费用核算；区分 QDII T+0 LOF 与境内股票 T+1 LOF（严格拦截当日卖出）。
   - 实现 BUY→部分SELL→清仓闭环，严格守恒资金与费用。
3. **港股与期货隔离执行（Task-08）**：
   - 建立双币种隔离账本 `MultiAssetLedger`（CNY 与 HKD 严格隔离，零串币）。
   - 建立期货保证金核算模式，支持开平仓、保证金占用与释放、合约乘数与平仓盈亏。
4. **候选池筛选与预算控制（Task-09）**：
   - 建立 `MultiAssetCandidateSelector` 与 CLI `trademind market-select`，按流动性排序并受 `top_k_per_market` 与 `max_total_candidates` 硬顶截断，零模型调用。
