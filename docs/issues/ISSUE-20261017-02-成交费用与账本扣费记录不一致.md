# 成交费用与账本扣费记录不一致

## 问题与影响
真实PaperBroker+OMS的同账户合成成交：100份513050.SH@1.50，账本扣150.10、事件fee=0.10，但返回Fill.fee和fills.payload_json.fee都为0。后续按Fill导出/核对会把手续费看成0；日报当前从account_events note提取费用，是正确0.10，不能说日报已少计或重复扣费。

## 根因与代码
src/trademind/execution/paper.py两个_fill_at_*构造Fill时fee=0；OMS._poll_fill先repo.save_fill(fill)，后ledger.apply_fill返回实际费用，局部fee没有同步回返回/持久化Fill。Ledger.apply_fill重新compute_fees并写事件/扣款。Fill.fee未声明是占位费用，形成同一成交两套事实；Repo.fills_for_order直接读出0。

## 独立复现（Task17-07）
临时_day2_env，账户1000；用_ack_order生成本账户ACK BUY100@1.50并冻结160；仅mock分钟数据返回次分钟OHLC1.50、volume1000/amount1500，PaperBroker与OMS均实际运行。poll_fill结果：返回fee0、fills_for_order.fee0、cash849.90、fill_buy.note='fee=0.10;price=1.50'。该反例独立于跨账户问题，无收费请求或生产写入。既有OMS/恢复/账本33项通过，未覆盖Fill与事件一致性。
