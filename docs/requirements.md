## 已确认的用户目标

1. 建立以 AI 为决策核心的股票交易系统，名称 TradeMind。
2. 结合 JEV 与大模型；初始希望使用 DeepSeek 的快速模型，具体可用模型需核实。
3. AI 分析股票并产生买入、卖出判断；传统程序主要作为数据、计算、评估和执行基础设施。
4. 当前对话只管理文档，另一个对话依据 Task 逐项开发。
5. 预先建立覆盖交付范围的架构、Task 和实际问题 Issue，按完成门禁推进。
6. 首期优先支持 A 股，数据使用 Tushare、AKShare、BaoStock 的免费可用部分，不默认购买付费接口。

## 规划的第一版

下面是根据讨论整理的实施提案，执行 TASK-04 时确认范围和参数。

- 单用户、本地优先、A 股优先、股票多头、无杠杆，先离线回放再模拟交易。
- 行情、基本面、新闻、宏观、资金流经适配器采集；拿不到的数据明确缺失，不编造。
- Python 负责数值和账户账本；大模型负责编排角色化投研、辩论、交易和组合意见。
- JEV 提供实时状态的结构化判断，Trader 是必要的投资意图出口。
- 每次决策保存证据、时间、模型与 Prompt 版本、意图、风控结果和订单链。
- 持仓后也持续评估 SELL / HOLD，不只做入场；成交后形成结果与反思。
- 具备回放、模型消融对比、费用与滑点、概率校准、运行监控和可视化操作界面。
- 启动默认模拟模式；实盘适配独立阶段，须确认市场、账户、权限和上线门禁。

## 第一版完成定义

TASK-04～23 的必需工作完成，相关阻塞 Issue 解决；从数据进入到 AI 决策、Guard、模拟成交、持仓更新、卖出、结果和反思的链可复现；回放隔离、重启恢复、重复消息和模型故障有验证证据。

模拟观察验收是工程稳定性验收，不能证明盈利。模型增益评估可以得到负结果，照实记录仍可完成研究交付，不能用更换区间隐藏失败。

视觉、多市场、实盘不作为第一版必需项。全部规划 Task 完成也不能代表未来不会产生新 Issue。

## A 股数据与执行约束

数据路线采用 ARCH-001 的三源适配方案，外部核验依据见 [数据研究](research/20261007-a-share-free-data.md)。AKShare / BaoStock 优先候选，Tushare 仅使用已具备免费权限的接口，无 Token 或权限不足不阻塞模拟基础链。具体数据集主源由 TASK-08 实测决定。

MarketProfile 必须按适用证券和交易所现行规则验证交易日历、集合竞价/连续竞价、午间休市、交易单位、可卖数量、价格限制、停牌、公司行动和费用，不把所有板块与品种硬编码为同一规则。首版建议先收敛普通股票模拟范围，ETF、融资融券和券商实盘须另确认。
