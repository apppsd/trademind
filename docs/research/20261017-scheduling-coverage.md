# 买入触发窗口与模型调度覆盖评估

数据源：生产库只读（10-16全天1008条intents、15条strategy_plan_history、24次model_calls账）+ fast_pipeline/strategy_planner 冷却与缓存语义核对。离线分析，零新增调用。

## 覆盖事实（2026-10-16真实会话）

- 1008 条 WAIT：**978（97.0%）为全账户300秒冷却**、29（2.9%）策略无可执行条件、1（0.1%）JEV证据不确定。**1008 WAIT ≠ 1008 模型调用**（当日实际模型请求 24/100；冷却拒绝发生在 planner 前置，零成本）。
- 15 个计划窗口时长全部 ≈1197 秒（20分钟 TTL）——**窗口长于300秒节奏**：每个窗口含 ≥4 个评估采样点，计划本身不会被节奏整体跳过。
- BUY 权限窗口 2/15（10:03 518880、11:18 513050）；当日 0 次 BUY 意图、1 次 JEV 评估（证据不确定 WAIT）。**短暂入场条件（Issue16-02 的 11:21/11:27 形态）**：入场条件满足若仅持续 <300 秒且不落在采样点上，会被冷却跳过——这是唯一的真实覆盖缺口，且无法从留档回填当时特征值精确计数（未来行情不回填）。

## 方案比较

| | A. 保留现状（300s全账户） | B. 预算内候选调度（设计） |
|---|---|---|
| 短时信号覆盖 | 持续<300s的信号有错过的采样风险（缺口所在） | BUY权限计划存在时例外评估（建议60-120s间隔），覆盖显著提高 |
| 费用上界 | 现状24次/日 | 每BUY窗口限评≤4次×3标的×7窗口≈84次≤预算100，硬顶不变 |
| 持仓优先 | 不变 | 不变（HOLD/SELL路径与候选调度独立） |
| 公平性 | 固定轮转 | 候选按plan到期时间排序，同plan单窗口限次去重 |
| 契约影响 | 无 | **改变已冻结的300秒契约**：需需求+Architecture同步 |
| 去重/重试 | 冷却即去重 | per-plan last-eval记录，评后到下次刷新不重评；预算不足回落A |

## 结论与设计（可评审，未实施）

- **现状能力边界（明确）**：300 秒采样对 ≥20 分钟的plan窗口覆盖充分；缺口仅限"入场条件短暂满足"（<300s）形态。该形态当日未造成可证实的损失（0 BUY 意图当日也无成交诉求）。
- **候选设计 B**（若获契约变更授权）：新增 `candidate_eval_interval_seconds`（建议 120，默认=沿用现状 300 以保持兼容）；触发条件=存在 BUY 权限且未过期的活跃计划；每计划每窗口评估次数上限 4；预算剩余 < 阈值回落现状；与持仓风险退出、探针/排空边界正交。实施需同步 requirements-jev-fast-decision 与新 Architecture，配离线真实路径回归（短时触发/预算不足/持仓退出/异步重检）。
- **建议**：先以现状再观察数个交易日（1008/24 的 cooled-to-called 比说明预算余量极大，B 的费用风险低但契约变更应基于更多短时信号样本），B 的设计留存备审。
