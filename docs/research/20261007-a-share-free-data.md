# A 股免费数据源核验与接入提案

核验日期：2026-10-07。用户已确认首期 A 股、使用 Tushare / AKShare / BaoStock 免费数据；本文区分网页核验与接口实测，实际选定设计见 ARCH-001。

## 已核验的外部描述

- AKShare 官方股票文档列有沪深京行情快照接口 stock_zh_a_spot_em，以及多类股票数据接口。成交量字段标为手、成交额为元、涨跌幅为百分数，不能直接与其他源混用。[官方股票文档](https://akshare.akfamily.xyz/data/stock/stock.html)
- Tushare Pro 按接口设积分权限及频次规则；是否可免费使用要检查账号与具体接口，不能以 SDK 可安装推导数据可用。[官方权限说明](https://tushare.pro/document/1?doc_id=108)
- BaoStock 官网提供历史 A 股 K 线与复权因子的资料入口。本次旧 Python API 文档路径不可读取，因此不据此确认具体分钟范围、更新时间或 SLA。[官网](https://www.baostock.com/)

## 执行核验清单

1. TASK-05 记录官方 URL、库版本、使用范围与免费权限；不购买、不注册账户、不索取真实 Token 到聊天。
2. TASK-08 对少量样本做只读探针，记录具体接口、字段、更新时间、分页/限流、历史范围、错误与数据 hash；真实响应脱敏。
3. 将三源证券代码映射到统一 instrument_id，保留 exchange、原始代码及证券类型；不得仅凭数字前缀猜交易所。
4. 每个接口独立转换成交量、金额、百分数、币种和时区；保存不复权成交价与有明确版本的研究复权价。
5. 切换只允许同数据集、同口径且新鲜的源。冲突不平均价格，缺失不填 0；记录选择原因和来源变更，无法匹配则暂停相关决策。
6. 免费报价没有可信源时间时标为时间未知，抓取时间不能充当交易所行情时间；新鲜度不达标不支持相应快速决策。
7. 今天下载的历史数据不能伪造当时系统可见时间。分别记录真实采集时间、可核实公告时间与 availability_basis；无法证明历史版本时排除严格时点回放或明确标注近似数据集。
