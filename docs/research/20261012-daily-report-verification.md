# 每日交易报告验证

日期2026-10-12，TASK-20261012-04 / ARCH-012。本次新增只读报告、策略历史和自动刷新，不改变账户/交易/模型预算，不调用收费API。

## 实现
reports/daily.py读取同一SQLite只读事务快照，按上海日解析事件并重建期初/期末现金、冻结资金、持仓、成交及手续费。初始建账入金作为起始资本，其他入金/出金从收益剔除；交易盈亏已包含成交费用，不重复减手续费。缺期初持仓估值或有效期末价则总盈亏unknown，单列已实现收益，后者可能包含以前持仓收益。

模型费用优先账户预算当日/历史状态，分已结算估值与未知预留；使用配置费率，不代表供应商账单。库有多账户且调用表无account_id时，调用明细只作库级参考，账户费用仍以各自预算为准。审计行数与预算请求数不一致会提示，不清账。

策略history追加(account_id,plan_id)表，存脱敏有效草稿；旧计划只能读当前缓存，不能恢复已覆盖历史。报告包含留档决策、完整可用策略、成交/持仓/模型明细。

## 自动化与入口
- paper.finish时生成当日日报，失败只记录error_type，不改变运行结果/交易。
- workbench lifespan每60秒读取只读快照更新今日与昨日；后台无模型/行情/账户写入。进程停止期间不执行；启动后恢复。没有新系统定时任务。
- 工作台首页链接/reports/daily；/reports/daily/YYYY-MM-DD页面及/api/reports/daily/YYYY-MM-DD数据；无额外收费调用。
- CLI：python -m trademind.runner --config config/t0-container.local.toml daily-report --date 2026-10-12（容器内运行）。输出runtime/daily-reports/<account>/<date>.json/.md/.html。
- 文件分别原子替换，不是三文件事务；盘中暂报随时间更新，收盘后标日终快照，日终快照不等于交易验收完整。
