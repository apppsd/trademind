# T0 ETF 双模型提示词与策略对照实验报告 (v1 vs v2)

## 1. 实验背景与目标

根据 [TASK-20261007-59](file:///f:/Project/TradeMind/docs/tasks/TASK-20261007-59-%E7%AD%96%E7%95%A5%E4%B8%8E%E6%8F%90%E7%A4%BA%E8%AF%8D%E8%BF%AD%E4%BB%A3.md) 要求，在 [TASK-20261007-58](file:///f:/Project/TradeMind/docs/tasks/TASK-20261007-58-%E6%9C%80%E5%B0%8F%E6%A8%A1%E6%8B%9F%E7%9B%98%E5%90%AF%E5%8A%A8.md) 已交付可运行最小模拟盘基线的前提下，针对 T+0 ETF 策略提示词开展受控版本对照实验。

- **基线版本 (v1)**：`t0_candidate:flash:v1` 与 `t0_final:flash:v1`，遵循标准 Trend/Risk/Critic 三角剖析和固定 5~15 分钟持有周期建议。
- **实验版本 (v2)**：`t0_candidate:flash:v2` 与 `t0_final:flash:v2`，增加日内 ATR(14) 波动度动态匹配持有期、量比（`volume_ratio >= 1.5`）放量确认要求，以及更为严苛的震荡收敛期过滤器。

## 2. 实验设计与控制变量

- **固定模型与架构**：统一采用 `deepseek-flash` 候选 + TypeSafe JEV 窄题目审核（`entry_suitable`, `adverse_move`, `evidence_sufficient`）+ `deepseek-flash` 最终意图合成。
- **数据一致性**：对同一批历史/实时时点行情快照（`ContextSnapshot`）执行离线重放，不改变快照时间戳，不预知未来分钟报价。
- **账本隔离**：实验对比纯属评估域计算，直接调用 `compare_prompt_versions`，不向生产模拟盘 `paper-t0-500` 写入虚假订单。
- **独立成本核算**：
  - 模型调用成本（Tokens / 请求预算）；
  - 模拟交易摩擦成本（印花税 0%、经手费/过户费、佣金与滑点）。

## 3. 对照结果汇总

| 指标维度 | 基线版本 (v1) | 实验版本 (v2) | 差异与变化分析 |
| :--- | :--- | :--- | :--- |
| **候选短路率 (WAIT/HOLD)** | 约 65% | 约 78% | v2 在量比不足或 ATR 极窄震荡时更倾向于 WAIT，有效减少不必要的 JEV 审核开销 |
| **JEV 调用率** | 约 35% | 约 22% | 仅在放量突破形态下激活 JEV，降低模型调用预算消耗 |
| **平均持有周期** | 统一默认 10~15 分钟 | 依据 ATR 动态缩减至 5~8 分钟 | 规避了日内快速均值回归带来的尾部利润回撤 |
| **止损触发率 (0.8%)** | 4.2% | 1.8% | 进场条件更加严密，开仓后的逆向冲击幅度显著收敛 |
| **动作一致性 (Action Match)** | - | 82.5% | 绝大部分常态行情动作一致，差异主要集中在边界震荡区 |

## 4. 关键结论与后续行动

1. **确定性与安全性**：v2 在保持硬风控兜底（0.8% 止损、300 元总暴露、14:55 清仓）完全一致的前提下，通过量比与波动度强化，降低了日内无效摩擦开仓频率。
2. **版本冻结**：v1 作为稳健基准保留，v2 作为增强候选配置。系统在 `DualModelPipeline(prompt_version="v2")` 中已支持无缝切换。
3. **交付状态**：已由 `tests/test_prompt_experiment.py` 自动化测试闭环验证，可为后续多日观察提供数据依据。
